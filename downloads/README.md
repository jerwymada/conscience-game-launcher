# Downloads

This directory contains the official Conscience Game Launcher 1.2.1 Windows
artifacts.

- `ConscienceGameLauncher-Setup-v1.2.1.exe`: one-click x64 installer
- `ConscienceGameLauncher-v1.2.1-portable-win-x64.zip`: lightweight portable
  x64 edition
- `SHA256SUMS.txt`: integrity checksums for both files

Both application editions require .NET 10 Desktop Runtime x64 and Microsoft
Edge WebView2 Runtime. The Setup downloads missing prerequisites automatically.

These files are not digitally signed. Verify their checksums before execution.
